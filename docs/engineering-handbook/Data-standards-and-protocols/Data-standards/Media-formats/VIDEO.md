# MP4 (H.264/AVC or H.265/HEVC) for Video Delivery

MP4 is a widely supported container format for digital video. It is compatible with major browsers and media players and is commonly used for CH video collections (interviews, documentaries, digitized films). The codec used inside the MP4 container (e.g., H.264/AVC or H.265/HEVC) impacts quality, compatibility, and file size.


## When to use MP4

- Web delivery or streaming use cases.
- Embedding videos in web-based CH tools and exhibitions.

## When not to use MP4

- Uncompressed preservation masters (use preservation workflows/codecs and archival packaging as appropriate).
- High-resolution film scanning masters where preservation-specific standards are required.


## Relevance to Cultural Heritage (CH Cloud)

- Supported as a standard dissemination format.
- Provide captions (e.g., WebVTT) when available to support accessibility.


## Technical considerations

- Codec selection influences compatibility (H.264 generally widest support).
- Accessibility requires captions or transcripts for many use cases.
