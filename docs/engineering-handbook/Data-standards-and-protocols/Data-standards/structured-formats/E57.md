# E57 (Point Cloud Data)

E57 is a vendor-neutral, open format for LiDAR and 3D scanning point cloud data. It is used in conservation, archaeology, and architectural documentation for precise spatial recording.


## When to use E57

- Storing and exchanging high-resolution point cloud data.
- Level 1 ingestion of raw scans where preserving measurement fidelity matters.

## When not to use E57

- Web visualization without transformation (typically requires downsampling or conversion).
- Lightweight end-user tooling where compact formats are required.


## Relevance to Cultural Heritage (CH Cloud)

- Relevant for archaeological and architectural datasets.
- Often requires transformation into derived formats for visualization or analysis.

## Technical considerations

- Parsing requires specialized libraries.
- Capture metadata (device, CRS, units, acquisition parameters) must be preserved.
- Large file sizes require efficient storage and transfer strategies.
