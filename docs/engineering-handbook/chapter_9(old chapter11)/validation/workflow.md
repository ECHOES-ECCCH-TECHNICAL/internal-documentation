# Validation workflow (D6.2 §9.1)

This page expands the normative workflow into operational steps, with checklists and evidence outputs.

## Checklist: submission package
- resource identifier + version
- declared interoperability level
- metadata record location
- required artefacts (OpenAPI/schema/SHACL/etc., as applicable)
- runtime endpoints (if applicable)
- contact + escalation

## Checklist: outputs
- conformance report (requirement-by-requirement)
- validation logs / artefact outputs
- pointers to stored evidence
